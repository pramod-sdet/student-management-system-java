# Student Management System (Java)

This project is a simple **Student Management System built using Java**.  
It demonstrates basic **Java programming and Object-Oriented Programming (OOP)** concepts.

## Features
- Add student records
- View student details
- Update student information
- Delete student records

## Technologies Used
- Java
- OOP Concepts
- Collections

## Project Structure
-src/com/studentapp

## How to Run
1. Clone the repository
2. Open the project in any Java IDE (IntelliJ, Eclipse, VS Code)
3. Run the main class
